# 风格指南 · 《不回头》（工作片名）

> 60 秒 · 16:9 · 1920×1080 · 60 fps。全部画面由 canvas 代码绘制，全部声音由代码合成。
> 本文件定义「长什么样、怎么动、怎么响」；逐镜头细节见 [`shotlist.md`](shotlist.md)。

## 1. 总调子

**现实是金色的，梦是银色的。**

- **上半场（0–33.6 s，现实）**：得州清晨。发射时刻 12:48 UTC = 当地 07:48 CDT，太阳刚升起约 25 分钟、高度角约 5°，**正东方、贴着墨西哥湾海面**。整段现实都被这颗低太阳侧光/逆光照亮：长焦、热浪、雾气、金色边缘光、烟尘。镜头是「地面上的人拼命追着它拍」。
- **下半场（33.6–60 s，梦）**：没有大气、没有太阳当主光。光来自星空、土星的反光和卡冈图雅的吸积盘。低饱和、近乎单色的银白 + 暖白高光，巨大的尺度、缓慢的镜头、深黑。
- **一条暗线：环。** 开场是 33 台猛禽发动机的同心环（3 / 10 / 20），结尾是正面看卡冈图雅的光子环与吸积盘的同心环；两个环尺寸、位置一致，片尾最后一帧能无缝接回第一帧（抖音自动循环时会形成闭环）。
- **另一条暗线：留下些什么才能前进。** 助推器留在海里，26 颗卫星留在轨道，一台熄火的 RVac 留在梦里也不再点亮，真实的飞船回了家——剩下的继续往前。

## 2. 两个世界

| | 上半场 · 现实 | 下半场 · 梦 |
|---|---|---|
| 主光 | 5° 高度角的朝阳，来自东（画面按镜头定，见分镜） | 吸积盘 / 星光 / 土星反照，无「太阳当主光」 |
| 色温 | 暖：金、橙、铁锈、钢的冷灰做对比 | 冷中带暖白：银、灰蓝、奶白 |
| 镜头 | 长焦 400–800 mm 等效，压缩空间，热浪扭曲，跟拍有滞后 | 广角 24–35 mm 等效，巨大尺度，缓慢推拉 |
| 运动 | 地面震动（振幅跟随响度）、跟拍弹簧滞后 0.3–0.5 s | 零抖动（除虫洞），3–6 s 的长弹簧运镜 |
| 质感 | 颗粒更重、光晕偏橙、空气透视 | 颗粒更轻、光晕偏白、纯黑底 |
| 声音 | 以音效为主：轰鸣、爆裂声、蒸汽；音乐只是底下的持续音 | 以音乐为主：管风琴 + 弦乐 |

## 4. 字体

两套字体，均为 SIL OFL，按实际用到的字符**子集化**后以 woff2 放进仓库（`fonts/`），保证云端和本地渲染一模一样。

| 角色 | 字体 | 字重 | 用途 |
|---|---|---|---|
| 英文主行 | **Noto Serif SC**（思源宋体，其西文字形） | 400 | 三处文字的英文主行 |
| 中文副行 | **Noto Serif SC** | 600 | 三处文字的中文副行（手机上要看得清，所以用偏粗的字重） |
| 数字 / 时间码 | **IBM Plex Mono** | 400 | 日期、UTC 时间 |

**三处文字一律英文为主、中文在下。**

**排版规则（按 1920×1080 计）**
- 手机竖握看横屏视频时，1080 高度大约只剩 220 pt。所以：**英文主行 ≥ 64 px；中文副行 ≥ 52 px、字重 600**（约等于手机上 11 pt 的粗宋体，看得清）；时间码 ≥ 44 px。
- 文字只放在画面的暗处（暗琥珀色天空、星空、虫洞外圈的黑），不放在亮背景上。
- 中文字距 +60（0.06 em），数字行字距 +120，全部左对齐，挂在画面里真实存在的线上（海平线、星空中飞船的航向线、光环的切线）。**不居中、不贴角、不加底框。**
- 字色 `type` / `typeDim`，允许被画面里的光「照亮」（高光处加一点 halation），但不加描边、不加投影。
- 出现方式：**不用透明度淡入。** 用「机械式打字」——每个字符在 1 帧内出现，间隔跟音乐的 16 分音符（0.2 s）或打字音效对齐；字符出现时有 8 px 的弹簧下落（ζ=0.7，1.2 Hz）。离开方式：**跟着剪辑硬切走**。

## 5. 质感（统一的后期层）

所有镜头先画进一个 2D 场景层，再过一层 WebGL 后期着色器，保证全片质感统一：

1. **Halation / 光晕**：亮度 > 0.8 的部分做多级模糊叠回，半径随亮度增大；上半场光晕偏橙（`#FF9A5A` 乘性色），下半场偏白。
2. **胶片颗粒**：按帧号做种子的亮度噪声（mulberry32 → 蓝噪声近似），暗部强度约 3/255，亮部约 1/255。**颗粒同时承担抖动（dither），防止 8-bit yuv420p 下太空渐变出现色带。**
3. **暗角**：边缘压暗 10–14%。
4. **色差**：只在画面最外 15% 生效，最大 1.5 px，红蓝反向。
5. **热浪**：只用于上半场长焦地面镜头（S2、S3、S5）。低频流动噪声位移 1–3 px，越靠近地面/海面越强。
6. **运动模糊**：快速镜头（S1、S4、S12）在一帧内累积 4–8 个子帧（仍然是 seek(t) 的纯函数：子帧时间 t + k·Δ）。
7. **镜头光**：只给真实的强光源（太阳、发动机、光子环）——轻微横向拉丝 + 一个大光斑，不用任何「通用镜头光预设」，不做彩虹鬼影串。

## 6. 镜头语言

- **焦距即情绪**：地面 = 长焦（紧张、被压缩、够不到）；轨道 = 标准镜头（平静）；梦 = 广角（渺小、宏大）。
- **跟拍要「追不上」**：地面跟拍镜头对目标的跟随用临界阻尼弹簧卷积，镜头总是略慢于火箭，火箭会在画面里向上漂一点再被拉回。
- **太空里不抖**：S6 之后除虫洞外一律没有手持感；运镜是缓慢的、有惯性的推拉摇。
- **剪辑**：全部落在 0.8 s 节拍网格上（75 BPM）。硬切为主。只有三处「转场」，全部由画面里的光完成：
  1. S1 → S2：羽流白爆 → 云顶冒出的白热羽流（亮度匹配剪辑）；
  2. S10 → S11：飞船尾焰的光点 → 土星环上的高光（点光匹配剪辑）；
  3. S14 → S1（循环）：卡冈图雅正面同心环 → 33 台发动机的同心环（形状匹配剪辑）。
- **构图**：主体放在三分线上；只有首尾两个「环」是刻意的中心对称。
- **镜头运动参数**（闭式弹簧，见 §7）：

| 类型 | 频率 f | 阻尼 ζ | 用途 |
|---|---|---|---|
| 跟拍滞后 | 1.6 Hz | 1.0 | 地面长焦追火箭 |
| 慢推/慢摇 | 0.25–0.4 Hz | 1.0 | 太空、梦段运镜 |
| 物体弹入 | 1.2 Hz | 0.55–0.7 | 文字、卫星滑出舱门 |
| 冲击震动 | 8–14 Hz | 0.15 | 点火、热分离的冲击，指数衰减 |

## 7. 运动规则

- 不用线性插值和 CSS 缓动。所有运动来自三种闭式函数：
  - **弹簧阶跃响应** `x(t) = 1 − e^{−ζωt}(cos ω_d t + (ζω/ω_d) sin ω_d t)`（ζ<1），ζ=1 时 `1 − e^{−ωt}(1+ωt)`；
  - **弹簧跟随**：目标轨迹与弹簧冲激响应 `h(τ)=ω²τe^{−ωτ}` 的离散卷积（向过去采样 1.5 s / 90 个点），无状态、可任意 seek；
  - **物理轨迹**：上升段用恒定推重比近似的加速度积分（闭式），卫星用匀速漂移 + 自转，光线用测地线积分。
- 任何东西的「出现」都要有物理原因：被光照亮、从遮挡后出来、从舱门滑出、被点燃。**禁止单纯的透明度淡入。**
- 随机：只用 `mulberry32(seed)`；每个镜头、每类元素用固定种子；逐帧变化的噪声用 `hash(frame, seed)`。

## 8. 硬件参考（V3 构型，画的时候照这个来）

- **全箭**约 124 m：助推器约 72 m + 飞船约 52 m，直径 9 m，不锈钢本色。
- **超重助推器**：33 台猛禽 3，布局 **中心 3 / 内环 10 / 外环 20**；顶部一体化热分离环（带通风格栅）；栅格翼画成侧视时只露出两片（避免在数量上被挑刺）；机身有烟熏纵纹、结霜带随液位变化。
- **飞船 S41**：6 台发动机——中间 3 台海平面猛禽（小喷管）+ 外圈 3 台真空猛禽 RVac（大喷管）；两片前襟翼、两片后襟翼；迎风面黑色六边形防热瓦、背风面不锈钢；侧面的卫星释放舱门（「PEZ」开口）。
- **Starlink V3 卫星**：扁平的大矩形板，舱门里一颗接一颗滑出，**共 26 颗**。
- **羽流**：海平面 = 亮、不透明、橙白带马赫环；高空 = 急剧膨胀成巨大半透明的「水母」；真空 = 几乎看不见，只有喷口附近淡紫蓝，RVac 喷管本身烧得发橙。
- **不画**：发射塔的筷子臂、塔「夹住」助推器的任何暗示。地面镜头里发射塔一律被蒸汽云挡住或不在画内。

## 9. 声音调色板

- **乐器（全部代码合成）**
  - 管风琴：加法合成，音栓 32′/16′ 踏板、8′ 原音、4′、2⅔′、混合音栓；起音带「气流噪声 + chiff」，慢速进气膨胀；6 s 大教堂混响（FDN）。
  - 弦乐：去谐锯齿波合奏 + 颤音 + 低通，长音用 sul tasto 质感，推进段用顿弓 ostinato。
  - 钟琴：FM 合成的短促高音，用于 26 颗卫星。
  - 音效：次声轰鸣（棕噪 + 20–60 Hz 共振）、猛禽「爆裂声」（泊松脉冲 + 1–4 kHz 带通）、蒸汽嘶声、金属咔哒（模态合成）、涡轮泵降速（正弦下滑 900→200 Hz）、等离子呼啸、虫洞的反向混响 + 变调。
- **调性与节拍**：D 多利亚 → 结尾 D 大调（皮卡第三度）。75 BPM，4/4，**一拍 0.8 s、一小节 3.2 s**，所有剪辑点在节拍网格上。
- **声音即剧情**
  - 六声部和弦 = 飞船六台发动机。S6 一台 RVac 熄火时，**和弦里掉一个声部**（留下一个空洞），直到片尾 S14 才补回来，最后的和弦才完整。
  - S7 关机入轨：所有声音**硬切成 0.8 s 的绝对安静**，然后管风琴第一次完整进入。
  - S8：26 颗卫星 = 26 个钟琴音，每一个音对齐一颗卫星离开舱门。
  - S13：接近卡冈图雅时，ostinato 做**渐慢**（75 → 约 40 BPM），画面里尾焰的闪烁也同步变慢——用声音和画面一起表现时间膨胀。
- **原创性护栏**：主题动机自写（上行五度 + 级进下行，D–A–G–F–E–D 的变形），**不用**两音交替的管风琴 ostinato、**不用** A 小调上行琶音这两种最容易让人联想到现成配乐的写法。风格可以像，旋律必须是自己的。
- **响度**：整片 −14 LUFS（integrated），真峰值 ≤ −1 dBTP；合成阶段自带 4× 过采样真峰值限幅，ffmpeg 只做小幅线性修正。动态起伏：发射段短时 −10、入轨静默段 −24、卡冈图雅高潮短时 −9。
- **循环**：结尾和弦在 59.6 s 前收完，混响尾巴在 60.0 s 前落到 −60 dB；开头的次声轰鸣调在 D，循环接缝不突兀。

## 10. 禁用清单

- 渐变背景上居中的标题；所有东西都淡入；角落标签和画框边；通用粒子爆炸。
- 字幕条、底框、描边字、投影字；HUD/遥测叠加（画面上不出现 T+ 计时器、速度高度数字）。
- 发射塔筷子臂；「助推器被夹住」的任何画面。
- 《星际穿越》原片画面、原声、海报构图的复刻；汉斯·季默主题旋律。
- 画面里出现 Claude / Anthropic / Opus 字样或 logo。
- `Math.random`、`setTimeout`、CSS transition、渲染模式下的 `requestAnimationFrame`、跨帧状态。
