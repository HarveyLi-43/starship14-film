## 逐镜头

### S1 · 点火环 · 0.0–2.4
- **画面**：镜头在导流槽里正对上方，看助推器底部的发动机舱。**第 0 帧中心 3 台已经点着**（白热核心 + 光晕 + 横向喷出的蒸汽），没有黑屏起步。
  - 0.0–0.4 中心 3 台膨胀到最亮；
  - 0.4–0.8 内环 10 台顺时针依次点亮（每台 = 一次闪光 + 喷管口亮环 + 向外扩的火焰圆盘）；
  - 0.8–1.2 外环 20 台依次点亮，33 台组成完整的「曼陀罗」：蓝白核心、橙色羽流；
  - 1.2–2.0 离地：整个环向画面中心缩小（火箭在远离镜头上升），羽流柱正面冲下来，湍流翻卷；
  - 2.0–2.4 羽流吞没镜头 → 全画面白爆，在亮度顶点硬切。
- **镜头**：固定仰拍，0→3° 缓慢滚转；每圈点火一次冲击震动（10 Hz, ζ=0.15）；开启子帧运动模糊。
- **文字**：无。
- **声音**：0.0 次声重击（D1 36.7 Hz）+ 爆裂声起；0.4 / 0.8 各一次「砰」；轰鸣低通从 200 Hz 打开到 2 kHz；2.0–2.4 饱和成白噪声，在剪辑点**一刀切断**。
- **事实点**：33 台，3 / 10 / 20 布局。

### S2 · 凌日 · 2.4–6.4
- **画面**：从发射场西侧约 13 km 外、800 mm 长焦向东看（朝阳在正东）。
  - 2.4 白爆收成画面下方翻滚的蒸汽云：顶部被朝阳染成金色，下半部在阴影里，发射台和塔完全被云挡住；火箭的白热羽流正从云顶冒出；
  - 2.4–4.0 火箭升起，镜头带着弹簧滞后往上追（火箭先在画面里往上漂，再被拉回三分线）；热浪让一切边缘轻微晃动；
  - 4.0 太阳圆盘从画面顶部进入——巨大、发扁、边缘被热浪扭动，临边昏暗；
  - 4.4–5.6 **火箭剪影横穿日面**：助推器 + 飞船黑色剪影，羽流比太阳更亮（整箭高度约等于太阳直径——13 km、800 mm 下确实如此）；
  - 5.6–6.4 火箭越过日面上缘，羽流柱留在太阳前面。
- **镜头**：长焦上摇（跟拍弹簧 1.6 Hz, ζ=1），地面震动微抖（等声音到达后才开始）。
- **文字 1**（3.2–6.4，左三分，压在对着太阳曝光的暗琥珀色天空上）：
  ```
  STARSHIP FLIGHT 14                    ← Noto Serif SC 400，68 px，字距 +120，type
  2026.09.28 · 12:48 UTC                ← IBM Plex Mono 46 px，字距 +80，type
  星舰第 14 次试飞 · 北京时间 20:48       ← Noto Serif SC 600，52 px，typeDim
  ```
  3.2 第一行、3.6 第二行、4.0 起中文行逐字打出（每字 1 帧出现 + 8 px 弹簧下落）。随 6.4 硬切离开。
- **声音**：S1 的轰鸣被切断后，这里**几乎无声**——远处海风、极低的管风琴 D 持续音、打字的轻响（我们在 13 km 外，声音还没到）。**4.8 声浪到达**：爆裂声和轰鸣滚进来，地面震动随之开始。
- **事实点**：12:48 UTC = 当地 07:48 CDT，日出后约 25 分钟，太阳在东、高度约 5°，火箭向东飞向太阳；不画塔和筷子。

### S3 · 声障 · 6.4–9.6
- **画面**：换成从南侧看的侧面长焦，太阳在画右。火箭向右上方转弯（画面方向「向右 = 前进」从这里一直保持到片尾）。天空从 `skyHigh` 过渡到 `skyZenith`；羽流拉长，橙白带马赫环，被低太阳从右侧照亮。
  - 7.2–8.4 跨声速：一圈半透明白色凝结云在级间段/飞船周围闪烁、忽隐忽现（又一个环）；
  - 8.4–9.6 凝结云散去，火箭变小，羽流开始变宽，身后的尾迹一侧金色、一侧蓝灰。
- **镜头**：长焦追拍 + 焦距 600→800 mm 缓推，抵消火箭变小；热浪随高度减弱。
- **声音**：满轰鸣 + 爆裂声；管风琴 D + A 五度低低垫着；8.0 最大动压处一记深沉的闷响。

### S4 · 热分离 · 9.6–12.8
- **画面**：约 65 km 高度，天空近黑，下缘是地球的蓝色雾线。箭体在高空被朝阳照得金白发亮；羽流膨胀成巨大的半透明「水母」。
  - 9.6–10.4 助推器大部分发动机关机，羽流塌缩成细柱（只剩中心 3 台）；
  - **10.4 热分离**：飞船发动机在仍连着的状态下点火，火焰从热分离环的格栅**一圈向外喷出**，冲击环扩散；
  - 10.4–11.6 分离：飞船带着淡紫蓝真空羽流向右上离开；
  - 11.6–12.8 助推器落在后面开始缓慢翻转，热分离环还烧得发橙。
- **镜头**：长焦锁定级间段；10.4 冲击震动 + 一次「自动曝光」压暗回弹；分离后镜头转去跟飞船，助推器滑出画左。
- **声音**：轰鸣逐渐低通变薄（空气稀薄的听感）；10.4 一记脆裂 + 金属共鸣 + 呼啸；飞船发动机是一个更高、更干净的新音色。

### S5 · 海上 · 12.8–16.0
- **画面**：墨西哥湾海面，船上低机位长焦；太阳低在画右，海面上一条金色倒影光路。**画面里没有塔、没有陆地**，只有海。
  - 12.8–13.6 助推器尾朝下从画面上方落下，满身烟熏纹，栅格翼张开（侧视只露两片）；
  - 13.6 着陆点火，一团刺眼的光照亮海面；
  - 14.4 收到中心 3 台；羽流砸到海面，**一圈冲击水环**向外扩散，水雾和蒸汽径向喷开；
  - 15.2 助推器减速到几乎悬停，然后坐进海里，发动机关机；
  - 15.2–16.0 巨大的蒸汽云翻滚而出，被朝阳逆光照成金色，助推器顶部还露在蒸汽里、刚开始倾斜——在它倒下前剪走。
- **镜头**：船上的慢摇（0.15 Hz 滚转）+ 长焦跟随下摇。
- **声音**：12.8 一串音爆「嘭–嘭」；着陆点火轰鸣；海水嘶声；关机后只剩蒸汽和浪。
- **事实点**：助推器**海上降落**，不是塔上被夹住。

### S6 · 少了一台 · 16.0–19.2
- **画面**：后侧方美术镜头：长长的不锈钢箭体斜着伸向画面右上、延伸出画外，尾端朝向镜头左侧，下方是地球。尾端是六台工作中的发动机：中间 3 台小喷管的海平面猛禽、外圈 3 台大喷管的 RVac（喷管本身烧得发橙，真空羽流是淡紫蓝的巨大钟形）；后襟翼。下方是朝阳里的地球（海洋 + 云街），上方是弧形地平线和一线蓝色大气。
  - 16.8 离镜头最近的那台 RVac 羽流抖了两下；
  - **17.2 熄火**：羽流 3 帧内消失，喷管开始从 `nozzleHot` 冷却到 `nozzleCool`（约 2 s）；
  - 17.6–19.2 其余发动机做几度摆动补偿推力不对称；飞船继续向前。发光的一圈发动机里，多了一个黑洞。
- **镜头**：朝熄火喷管缓推（0.3 Hz）；真空中不抖。
- **声音**：发动机低鸣下是一个六声部的持续和弦（管风琴 + 弦乐）。**17.2 和弦掉一个声部**，留下一个空洞；涡轮泵降速的下滑哨音（900→200 Hz）；一声低沉的金属「咚」。
- **事实点**：上升段**一台 RVac 提前关机**；其余五台继续工作。

### S7 · 入轨 · 19.2–23.2
- **画面**
  - 19.2–20.0 侧视：剩下的五台同时关机，真空羽流收拢消失，喷管余光；
  - 20.0–20.8 **失重滑行**：一片片冰晶从箭体上剥落，在阳光里闪着飘开（真实飞行影像里常见的细节）；
  - 20.8–23.2 镜头后拉 + 上升（0.3 Hz 弹簧）：地球弧线占满画面下部，薄薄一层蓝色大气，海面上一块太阳反光；飞船变成地球上方一根发亮的钢针。人类的火箭第一次真正入轨。
- **镜头**：35 mm 近景 → 广角后拉，平稳。
- **文字**：无，让画面和安静说话。
- **声音**：19.2 关机声 → **20.0 所有声音硬切成 0.8 s 绝对安静** → 20.8 管风琴第一次完整进入（D，宏大，长混响），弦乐持续音托底（仍是缺一个声部的五声部）。

### S8 · 二十六 · 23.2–27.2
- **画面**：贴着箭体侧面的推轨：不锈钢表面、零星霜斑，画面下缘是迎风面的一排黑色防热瓦；中间是一条长长的横向舱门。
  - 23.2–23.6 舱门滑开（弹簧 ζ=0.7），里面是叠放的卫星；
  - 23.6–26.93 **Starlink V3 一颗接一颗滑出，共 26 颗**，间隔 0.133 s：每颗扁平的大板子出舱时微微倾斜，在阳光里闪一下镜面反光，然后缓缓向左上漂离；
  - 镜头同时沿箭体后退，把释放出去的卫星拉成一条通向地球边缘的斜线光点——26.93 时 26 个光点全部可见、可数；
  - 26.93–27.2 舱门开始关闭。
- **镜头**：慢速横移（0.3 Hz）→ 后拉揭示整串卫星。
- **声音**：26 个 FM 钟琴音，每个音对齐一颗卫星出舱（16 分三连音，D 多利亚里先上行后下行）；每颗下面垫一声轻微的机械锁扣；弦乐铺底。
- **事实点**：S41 入轨后释放 **26 颗 Starlink V3**。

### S9 · 分岔 · 27.2–33.6
- **画面**
  - 27.2–28.0 **延时**：轨道上的飞船剪影，地平线上**两次轨道日出**闪过（两圈 ≈ 3 小时），下方云层飞速流动；
  - 28.0–29.6 北太平洋夜面上空，远处地平线透出晨昏线的橙色。飞船调头尾朝前（尾部指向画右 = 运动方向），一台海平面猛禽点火：**离轨**，淡蓝紫的羽流照亮箭体；
  - 29.6–30.4 飞船朝地球落下、离开镜头；镜头留在轨道上。它变成一个点，再变成粉橙色的**再入等离子体**，一道流星划向漆黑的洋面；
  - 30.4–31.2 流星没入晨昏线附近的雾气，洋面上一闪极小的光（**溅落**）——然后什么都没有了。镜头独自悬在夜晚的地球上方。
  - 31.2–32.0 镜头慢慢抬头，离开地球，转向星空——**它在那儿**：在晨昏线之外被阳光照亮，机头指向远离地球的方向（画右上），那台熄火的 RVac 依然是黑的。发动机点火，蓝白色；
  - 32.0–33.6 它向星空加速远去。
- **镜头**：延时段固定；离轨段缓推；30.4 起一次慢速的上摇（0.25 Hz 临界阻尼），从「看地球」变成「看前方」。
- **文字 2**（31.6–33.6，放在飞船航向线的左下方，星空里的空处）：
  ```
  But one didn't turn back.     ← Noto Serif SC 400，76 px，type
  但有一艘，没有回头。            ← Noto Serif SC 600，56 px，typeDim
  ```
  英文逐词出现、中文逐字出现，节奏对齐点火后发动机的明暗脉动。随 33.6 硬切离开。
- **声音**：延时段两次「日出」的膨胀音；离轨点火的低鸣；等离子体呼啸，音高下滑；**30.4 静默**，只剩一根极高的小提琴泛音；**31.2 点火——主题动机第一次出现**（上行五度 + 级进下行），弦乐跟进。
- **事实点**：约 3 小时后**离轨、再入、北太平洋溅落**——真实的飞船回家了，画面如实交代；从 31.2 起是虚构：「它没有回头」。

### S10 · 远去 · 33.6–36.8
- **画面**：尾追镜头，从后 3/4 看飞船全力加速（两台 RVac + 三台海平面猛禽，熄火的那台仍然是黑的）。地球在 2 s 内从占满画面下部缩成一颗蓝色弹珠；35.2 月球从画左擦肩而过——一大片灰色的月牙飞速掠过；36.0–36.8 镜头落到飞船正后方，飞船拉开距离，尾焰变成一个光点。
- **色调**：暖色从这里开始褪去，过渡到银色。
- **镜头**：带滞后的追拍弹簧（飞船往前冲，镜头追不上）。
- **声音**：管风琴 ostinato 起（8 分音符脉动），弦乐渐强；月球掠过的呼啸。

### S11 · 土星 · 36.8–41.6
- **画面**
  - 36.8 **光点匹配剪辑**：S10 最后的尾焰光点 = 这一镜里土星环上的一个高光点，同一位置；
  - 巨大的土星占画面右侧三分之二，从略低于环平面的角度看：环是一道横切画面的细亮弧，环在星体上投下一条暗带，夜面被环的反光微微照亮；飞船是左下前景里一个带尾焰的小亮点，向右往画面深处飞；
  - 38.4 镜头从左向右缓摇越过土星边缘，露出一颗**完美的球**：它的内部是另一片星空被扭曲的暖色影像（「另一边」），球的边缘一圈爱因斯坦环，背景恒星被拉成弧；
  - 40.0–41.6 飞船朝它飞去，球在变大。
- **镜头**：广角，慢摇 + 慢推（0.25 Hz）。
- **声音**：ostinato + 弦乐；38.4 虫洞揭示时一个低沉的管风琴音簇；远处的泛音微光。
- **说明**：致敬但不复刻原片构图——我们从环平面下方看、虫洞在土星边缘外，而不是原片的那种正侧面「飞船掠过土星环」构图。

### S12 · 穿越 · 41.6–44.8
- **画面**
